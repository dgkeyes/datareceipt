# datareceipt: Pull Your Data Receipt Data into R

Data Receipt <https://datareceipt.io> collects validated spreadsheets
from the people you ask. This package pulls what they sent into R as
typed tibbles: list your requests, read a request's column spec, and get
every accepted row across all submissions in one call.
